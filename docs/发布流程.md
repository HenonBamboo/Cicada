# 发布流程

本项目发布 Windows 11 x64 直接运行 EXE 和便携 ZIP，不生成安装向导。

1. 更新 `CHANGELOG.md`，并保持 `package.json`、`src-tauri/Cargo.toml`、`src-tauri/tauri.conf.json` 版本一致。
2. 确认 `LICENSE`、`PRIVACY.md`、`THIRD_PARTY_NOTICES.txt` 与当前代码、锁文件一致。
3. 按改动范围完成格式、类型、前端构建和 Rust 检查。
4. 运行：

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File scripts/package.ps1
   ```

5. 在本机 Windows 11 上确认启动、模型配置、任务写入、重启后数据保留、快捷键、便利贴和备份恢复。
6. 核对 `releases/SHA256SUMS.txt`，退出所有旧进程后从便携 ZIP 解压并再次启动。
7. 提交发布变更并创建与版本一致的 Git 标签，例如 `v0.1.0`。
8. 在同一 GitHub Release 上传 EXE、ZIP 和校验文件。该标签必须包含生成二进制所对应的完整源代码、锁文件和构建脚本。

发布目录属于生成物，不提交到 Git。未完成的人工检查应如实写入发布说明。
